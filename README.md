# HabitQuest

> A gamified productivity app by **XCURSION STUDIOS**

HabitQuest turns your daily habits and goals into an RPG progression system. Complete habits, earn XP, level up your character, and build real-world consistency through game mechanics that make discipline feel rewarding.

-----

## Features

### Core Gameplay

- **Daily Habits** — Track habits with difficulty ranks (F through S) and stat types. Build streaks, earn XP and gems on every completion
- **Quests** — Larger one-off goals with notes support. Up to 5 completable per day, with extra slots purchasable via gems
- **Skill Tree** — 5 branches (Physical, Mental, Spiritual, Social, Emotional) × 4 tiers each, plus 3 cross-branch unlock nodes. Earn 1 skill point per level
- **Penalty System** — Missed habits increase your Abyss Depth. A morning report delivers the damage and tracks recovery

### AI Coaching

- **Daily Briefing** — Personalised morning analysis generated by Gemini AI, based on your actual stats, streaks, mood, and history
- **AI Coach Chat** — Direct conversation with an AI that knows your character. Suggests quests, identifies weak points, gives tailored advice
- **Bonus Missions** — AI-generated one-off missions targeting your specific neglected areas

### Progression

- **5 Stats** — Physical, Mental, Spiritual, Social, Emotional — each tied to specific habits and tracked on a radar chart
- **Class System** — 9 class tiers from Beginner to Elite, unlocked by level
- **Mood System** — Set your daily mood each morning for XP multiplier effects
- **Shadow Missions & Boss Battles** — Weekly challenges and bonus objectives

### Customisation

- **8 Themes** — Each with a distinct colour palette and background tint (Classic Gold, Crimson, Void Purple, Jade, Iron, Ember, Frost, Toxic)
- **3 Aesthetics** — Full visual overhauls with different fonts, card styles, and colour systems (Neon City, Ancient Scroll, Void Realm)
- **Live Preview** — Preview any theme, aesthetic, or cosmetic for 5 seconds before buying
- **Shop** — Spend gems on temporary boosts, permanent upgrades, cosmetics, and visual unlocks

### Onboarding & Options

- **8-Step Guide** — Shown on first login, re-accessible anytime from Options
- **Options Screen** — Theme switcher, guide access, account management, progress reset

## Setup

### Prerequisites

- Node.js 18+
- A Supabase project
- A Google Gemini API key

### 1. Clone & install

```bash
git clone https://github.com/xcursion-studios/habitquest.git
cd habitquest
npm install
```

### 2. Configure environment

Create a `.env.local` file in the project root:

```env
VITE_SUPABASE_URL=https://your-project.supabase.co
VITE_SUPABASE_ANON_KEY=your-anon-key
```

### 3. Supabase setup

Run this SQL in your Supabase SQL editor to create the profiles table:

```sql
create table profiles (
  id uuid references auth.users on delete cascade primary key,
  game_state jsonb,
  updated_at timestamptz default now()
);

alter table profiles enable row level security;

create policy "Users can read own profile"
  on profiles for select using (auth.uid() = id);

create policy "Users can upsert own profile"
  on profiles for insert with check (auth.uid() = id);

create policy "Users can update own profile"
  on profiles for update using (auth.uid() = id);
```

### 4. Deploy the AI proxy Edge Function

The app uses a Supabase Edge Function to proxy Gemini API calls securely (keeps your API key server-side).

```bash
supabase functions deploy ai-proxy
supabase secrets set GEMINI_API_KEY=your-gemini-api-key
```

### 5. Run locally

```bash
npm run dev
```

### 6. Deploy to Netlify

Connect your GitHub repo to Netlify. Set the same environment variables (`VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`) in the Netlify dashboard under Site Settings → Environment Variables.

Netlify will auto-deploy on every push to your main branch.

## Game Systems

### XP & Levelling

- Each habit has a difficulty rank with a base XP value (F=20 → S=500)
- XP multipliers apply from: mood, active boosts, skill tree nodes, permanent upgrades
- 400 XP per level. Each level-up grants 1 Skill Point

### Skill Tree

- 5 branches × 4 tiers = 20 nodes
- Tier costs: 1 / 2 / 3 / 4 Skill Points
- 3 cross-branch nodes unlock when two specific branch tiers are owned
- Effects include: XP bonuses, gem bonuses, Abyss reduction, stat doubling, mood modifiers

### Abyss System

- Missing a habit at rollover increases Abyss Depth by 1
- Completing a habit reduces depth by 1
- Depth 5+ activates the Abyss warning state
- Maximum depth is 20 (reducible to 10 via Resilience skill node)

### Quest Daily Limit

- 5 quest completions per day by default
- Extra slots purchasable for 20 gems each
- Resets at midnight rollover
